NpuStudio - feature list
========================
Start it by double-clicking NpuStudio.bat. Everything runs on this laptop - nothing you type or open is sent anywhere
(the only internet use is downloading AI models the first time a feature needs them).

Chips in this laptop:
  NPU        = Intel AI Boost (low power, quiet)
  Intel Arc  = the built-in Intel graphics
  NVIDIA     = GeForce RTX 4070 Laptop GPU (fastest, uses the most power)
  CPU        = the main processor (fallback when nothing else works)

------------------------------------------------------------
TOP BAR (on every tab)
------------------------------------------------------------
* Device picker (top right): choose which chip the AI features use.
    Auto      - uses the fastest chip for each job, based on a speed test done on this laptop.
    NPU       - only the NPU. Jobs the NPU can't do show a message telling you to pick another device.
    Intel Arc - only the Intel graphics.
    NVIDIA    - only the RTX 4070.
    All       - Upscale splits the picture's tiles across all chips at once; single-picture AI jobs
                (Image Gen, AI change) use the fastest chip for each step.
  A single chip you pick is always respected exactly. The change applies from the next job.
  Speed test results are in models\devbench.json (re-run with: venv\Scripts\python.exe devbench.py).
* Chip Monitor button: opens the Chip Monitor window (see the CHIP MONITOR section below).

------------------------------------------------------------
CHAT TAB  (Phi-3.5 mini, runs on the NPU)
------------------------------------------------------------
* Offline AI assistant. Type a message and press Enter. "Stop" stops the answer, "New chat" clears the conversation.
* First use downloads the model (about 2.2 GB, one time). The very first start takes about 2 minutes, then a few seconds.
* It can also do things on the PC (it only does these; it never deletes files or runs other commands):
    - open an app ("open spotify")                     - close an app ("close notepad")         ASKS YES/NO FIRST
    - set volume / louder / quieter / mute / unmute    - brightness to a level / brighter / dimmer
    - dark mode on / off                                - open a Windows Settings page ("open wifi settings")
    - open a website ("open youtube.com")               - web search ("search for pizza near me")
    - open a folder ("open my downloads")               - take a screenshot
    - timer / reminder ("remind me to stretch in 10 minutes")
    - battery level                                     - time and date
    - lock the PC  [UNTESTED - not tried, to avoid locking your PC during setup]
    - sleep [UNTESTED]                                                                                    ASKS YES/NO FIRST
    - restart [UNTESTED]                                                                        ASKS YES/NO FIRST
    - shut down [UNTESTED]                                                                      ASKS YES/NO FIRST
* Tip: say exactly what you want ("set volume to 30"). Anything that closes, sleeps, restarts or shuts down
  asks you Yes/No first.

------------------------------------------------------------
UPSCALE TAB  (makes pictures bigger and sharper)
------------------------------------------------------------
* Open image, or drag a picture onto the window. Choose 2x, 4x, 8x or 16x, then Upscale, then Save.
* Two models:
    Fast  (Intel SR-1032)     - quick; fastest on Intel Arc (about 0.025 s per tile).
    Sharp (Real-ESRGAN x4plus)- best detail; fastest on NVIDIA (about 0.24 s per tile vs 0.52 Intel Arc,
                                0.64 NPU, 3.8 CPU).
* Denoise tick box for grainy pictures.
* Device = All splits the tiles across NPU + Intel Arc + NVIDIA at the same time.
  Measured on a 1280x720 picture made 4x bigger:
    Fast : NPU 1.5 s, Intel Arc 0.9 s, NVIDIA 1.0 s, All 0.47 s  -> All is about 2x faster.
    Sharp: NPU 15.9 s, Intel Arc 12.8 s, NVIDIA 3.6 s, All 5.8 s -> for Sharp pick Auto or NVIDIA (All is slower,
           because the slower chips hold up the NVIDIA card).
* 8x and 16x run the model more than once. [8x/16x not re-tested with the new device picker]
* Memory limit: the finished picture may use up to 18 GB; sizes that won't fit are blocked with a message.
* Click either picture to open the zoom/compare window.
* "Send to Edit" passes the result to the Edit tab.

------------------------------------------------------------
IMAGE GEN TAB  (make a picture from a text description)
------------------------------------------------------------
* Type what you want (and optionally what you don't want in "Negative"), pick a size, press Generate.
* Model: LCM Dreamshaper v7 - about 4 steps, a few seconds per picture.
    Intel Arc / NPU / CPU: OpenVINO version (about 1 GB, downloads on first use).
    NVIDIA: the original model through CUDA (downloads to models\hf on first use).
  Measured (512x512, 4 steps): NVIDIA 1.5 s, Intel Arc 3.3 s, NPU 8.5 s.
  Device = All: [UNTESTED for Image Gen] the main step runs on the NPU and the rest on the graphics chip.
* Tip: describe the picture ("a red fox in snow, photo"), not a command.
* Sizes up to 2880x1800 and more: it draws at about 768 px, then upscales with Fast or Sharp ("Upscale with").
* Steps (1-12) and Seed (same seed = same picture). "Send to Upscale" and "Send to Edit".
* The first time a new size is used it takes a minute or two to prepare; after that it is quick.

------------------------------------------------------------
EDIT TAB
------------------------------------------------------------
Basic tools (no AI, instant):
* Open / Save (PNG keeps transparency, or JPEG), drag and drop, Undo / Redo (Ctrl+Z / Ctrl+Y, last 20 steps).
* Rotate left/right/180, Flip horizontal/vertical, Resize.
* Crop with an aspect choice (Free, 1:1, 4:3, 3:2, 16:10, 16:9, 2880x1800 screen, 9:16).
* Brightness, Contrast, Saturation, Sharpness sliders and filters (B&W, Sepia, Blur, Sharpen, Warm, Cool), then Apply.
* "Send to Upscale".

AI tools:
* AI remove background (IS-Net) - makes the background transparent. Fastest on Intel Arc (about 0.1 s),
  also runs on NPU (0.2 s). About 180 MB download on first use.
* Brush + AI erase (LaMa) - paint over something with the Brush and click AI erase to remove it and fill
  the gap. Fastest on Intel Arc (about 0.5 s). Can't run on the NPU. About 210 MB download on first use.
* Clear mask - removes your brush strokes.

AI change... (pop-out window) - describe a change in plain words:
* Analysis box: when the window opens, a vision AI (Phi-3.5-vision, on Intel Arc) describes the picture, so it
  knows what is in it. First use downloads about 2.3 GB and loads in about a minute; then about 5 s per picture.
  "Re-analyze" refreshes it. The model is unloaded after 5 minutes of not being used, to save memory.
* "What do you want to change?" - type e.g.
    "change outfit to a red dress", "replace the rocket with a potted plant", "remove the helmet",
    "make it nighttime", "turn it into a watercolor painting".
* Which part changes (in this order):
    1. Your brush strokes on the main Edit picture (red), if you painted any.
    2. Otherwise, if you named a thing, it is found automatically a moment after you stop typing (cyan
       auto-mask). "Find target" re-runs it; Grow/Shrink makes the area bigger or smaller; you can still add
       to it with the brush. "Clear auto-mask" removes it.
       - Body parts and clothing use a body parser (about 0.2-0.4 s on Intel Arc; first use about 10 s):
         hair, face, head, outfit/clothes, shirt/top/jacket/coat, pants, skirt, dress, hat, shoes/feet,
         arms/hands, legs, skin, scarf, belt, bag, glasses.
       - Face details use a face parser: eyes, lips/mouth, nose, eyebrows, ears, neck, beard/chin area.
       - Anything else (rocket, flag, helmet...) uses CLIPSeg (under 1 s).
       Tested and working on a photo, a generated portrait and an anime-style drawing.
    3. The whole picture changes ONLY for clearly whole-picture requests (night, season, watercolor, style,
       lighting) or if you say "whole image". If it can't tell what to change, it says so and changes nothing.
* Wording it understands (her/his/their are fine, small typos like "charge" for "change" are fixed):
    "change her eyes to green", "make her hair blue", "give him a beard", "give her blue eyes",
    "hair to blonde", "turn his shirt into a hoodie", "replace the rocket with a plant", "remove the helmet".
* How it changes (shown in the status line as "Method: ..."; the Method box lets you force one):
    - Redraw (inpaint): a new thing ("outfit to red dress", "replace X with Y"). Redraws the area at full
      strength with style words from the analysis (e.g. "anime illustration" for drawings) and keeps the
      face, hair and hands out of the area for clothing. NVIDIA about 7-17 s; Intel Arc slower.
    - Recolor (pix2pix): same thing, new colour or material ("make the shirt blue", "make her hair pink").
      NVIDIA only, about 7-8 s.
    - "remove the ..." -> AI erase.
    - Whole picture (night, seasons, styles) -> InstructPix2Pix on NVIDIA (about 4 s, keeps faces); without
      NVIDIA it uses the Image Gen model's img2img (weaker, may change faces).
    - Results keep the original size; big pictures are brought back up with Sharp.
* Strength slider (1.0 for an area, 0.4 for the whole picture by default), "Prompt used" shows exactly
  what was sent to the image AI, progress bar, Apply / Undo / Cancel.
* Test results on the astronaut photo (NVIDIA): rocket -> plant WORKS; nighttime WORKS (face kept);
  outfit -> red dress: works on the anime drawing (the uniform becomes a red dress); on the astronaut photo
  the bulky space suit is redrawn as a suit again (did NOT become a dress); helmet -> flowers puts a small
  bouquet on the helmet; watercolor is only a light effect; flag -> bookshelf did NOT work (flag stayed).
  Tip: if the result is weak, paint the area with the brush, use Grow, and use words like
  "replace the X with Y". Undo always takes you back.
* AI change on Intel Arc / NPU only (no NVIDIA) [UNTESTED in the window]: whole-picture changes use img2img
  and area changes use inpainting on Intel Arc.
* First use on NVIDIA downloads InstructPix2Pix and SD-inpainting (about 2 GB each, to models\hf).

------------------------------------------------------------
CHIP MONITOR (window opened from the top bar)
------------------------------------------------------------
* One live chart per chip, stacked, updated every second: NPU (purple), Intel Arc (light sky blue),
  NVIDIA RTX 4070 (green). Each shows usage %, memory (dedicated / shared), power and temperature.
  The window can be resized.
* Power and temperature are only shown from real sensors, otherwise "N/A":
    NVIDIA: exact board power and temperature (NVIDIA driver, NVML).
    Intel Arc: power N/A, temperature N/A (no Arc-specific sensor; the graphics power counter reads ~0 W).
    NPU: power N/A, temperature N/A (Windows has no sensor for it on this laptop).
    The top line shows "CPU package power" (the whole processor, RAPL) on its own.
* Tip: leave it open while running a job to see which chip is doing the work.

* AI Change redraw engine (NVIDIA): any typed change - clothing ("outfit to red dress"), objects ("hat to a crown"),
  background ("make background a beach"), hair style ("make hair short and black"), pose ("make her wave",
  "arms crossed") and held items ("holding a coffee cup") - is drawn with ControlNet (anime lineart) + DreamShaper 8 inpainting.
  Same-shape swaps keep the original outline; shape changes use looser guidance. It draws 4 versions and keeps
  the one that really changed (and matches the colour you asked for). Recolor is only a clearly-labelled last resort.
  Body shape/proportions are never changed.
* Pose changes: wave, arms crossed / folded, hands on hips, one hand on hip, both arms raised overhead / hands up,
  peace (V) sign, hands behind head, thumbs up, pointing, arms relaxed at sides, salute, hand on chin (thinking),
  one arm raised. Common phrasings are understood ("cross her arms", "hands in the air", "thumbs-up", "arms down").
  OpenPose finds her skeleton, the arm joints are moved to the new pose and the arms are redrawn with OpenPose +
  lineart ControlNets together. The old arm position is first painted out as clean background, so no old-arm or
  fabric fragments remain. Her face, eyes, hair and body outline are protected (no body reshaping). Each version is
  re-checked: wrong pose, a hand on the chest/body, non-skin arms (gloves/sleeves), or a changed outline are thrown
  away; if every version fails, the status says NOT DONE and the original is kept.
* Hair changes cover the whole hair (long anime hair over the shoulders too); "short" hair also paints the old long
  hair area back to background. Background swaps use the cut-out's soft edge, so no grey halo around the person.
* Quality guards: colour must really match (strict hue + saturation/brightness - ochre/brown never counts as yellow,
  "bright" needs a vivid colour); the outfit mask is solid (holes filled, cap excluded) and feather-blended; versions
  with old-garment patches, blotchy texture, torn outlines or stray hands near a new background are thrown away, a
  second seed batch is tried, and if nothing passes the status says NOT DONE and the original is kept.
  Extra first-time download for poses: OpenPose ControlNet (~0.7 GB) + OpenPose detector (~0.5 GB).
* Style outfits: words like fire/flame, lava, ice, galaxy/space, floral/flower, camo, rainbow, leopard/cheetah, zebra,
  ocean, gold, sparkly, neon, plaid, polka dot and candy are expanded into a full description with the colours to
  expect ("fire dress" -> a dress made of fire and flames, red/orange/yellow). Every version is checked by CLIP
  (image vs. text: the request against "plain brown/grey cloth", "beige smock", "white uniform") and by colour;
  big flat blank patches and muddy low-saturation results are rejected when a colour is implied. "Plain/solid"
  wording is only used for plain colour requests. If nothing passes: NOT DONE, original kept.
  Extra first-time download: CLIP ViT-B/32 (~0.6 GB). After an AI Change is applied the picture is re-analyzed.

------------------------------------------------------------
NOTES / LIMITS
------------------------------------------------------------
* The NPU can't run LaMa erase or the inpainting step, and runs CLIPSeg poorly, so those use Intel Arc, NVIDIA or CPU.
* NVIDIA through OpenVINO is slow for some models; NpuStudio uses CUDA (torch) for NVIDIA where it matters.
* Problems? Look at error.log in this folder.

DESKTOP PC LINK (laptop + desktop working together)
- Device picker has two more choices: "Desktop PC" and "Both machines".
  - Desktop PC: Image Gen, upscaling, AI Change (redraw, pose, recolor), background removal and AI erase run on the desktop's RTX 4070 (12 GB); the picture is sent over the home network and the result comes back with progress.
  - Both machines: upscale splits the image by rows (desktop takes the larger, learned share; laptop does the rest), with fallback to local; generation and AI Change go to the desktop.
  - Both machines + AI Change: the candidate versions are drawn in parallel, every other one on the desktop, then all are checked here as usual.
  - If the desktop is offline, jobs run on the laptop and the status line says so.
- "Pair desktop..." button: enter the desktop's address and pairing key once (shown in the NpuStudio-Server window).
- Top bar shows "Desktop PC: online/offline"; the Chip Monitor shows the desktop GPU's use, memory, power and temperature (N/A when unreadable).
- On the desktop: NpuStudio-Server.bat starts the worker (home network + Tailscale only, pairing key required). AllowLaptop-Firewall.ps1 adds a private-network-only firewall rule.
- API.md documents the worker API for other apps (phone app): health, chip monitor, image gen, upscale, edit / AI Change, background removal, erase, and chat with PC actions (Yes/No confirm on the remote side).

- Chip Monitor: the desktop has its own orange usage graph panel (GPU use, memory, power, temp, jobs running), the same as the laptop's chips; it shows 'offline' with a flat line when the desktop can't be reached. The panels scroll when the window is small.

ANDROID COMPANION APP (NpuStudio-Companion.apk)
- A thin Android app that loads its screens from the desktop server (/app), so the app updates when the desktop updates.
- Tabs: Chat (PC actions with Yes/No confirm), Image Gen (with phone-wallpaper sizes), Edit / AI Change and Remove background (from the gallery), Upscale, Monitor (desktop plus the laptop when it's open), and Desktop status.
- Every job shows progress and has Cancel. Results can be saved to Pictures/NpuStudio or shared. You get a notification when a long job finishes in the background.
- Pairing: type the address and key, or scan the QR from Show-PairingQR.bat. If the desktop can't be reached, an offline screen offers Retry.
- Only connects to home-network and Tailscale addresses. For use away from home, see TAILSCALE.md and AllowTailscale-Firewall.ps1.
- The laptop app sends its chip stats to the desktop every 3 s while paired, so the phone can show them.
- Models stay on each machine; only pictures and settings travel over the network.
- Upscale on the phone: 2x / 4x / 8x / 16x (16x = two 4x passes), Sharp or Fast model, desktop chip choice (Auto / NVIDIA / Intel Arc / CPU / All), PNG or JPEG. Before running, the app checks the result size (18 GB memory budget, max 16384 px side / 160 MP for a phone) and offers to shrink the picture to fit.
- Gen on the phone: phone sizes plus the same sizes as the PC app, 4K and Custom; Upscale-with model, Steps, Seed.
- Edit on the phone: rotate/flip/crop/resize, brightness/contrast/saturation and filters, undo/redo, brush mask, AI erase, Remove background, AI Change with Method, Whole picture, Strength and Grow.
- Connection screen (tap the status pill): shows Home or Remote, online status and latency; saves a home address and a Tailscale address and switches between them automatically; Re-pair by scanning a QR.
- Chat controls the device you're chatting from. On the phone ("Control: This phone"): open apps, flashlight on/off, media volume up/down/set and mute, alarms and timers, open links (asks first), web search, battery level, copy to clipboard, notifications, save/share the last picture. Choose "Desktop PC" to control the desktop instead.
- The app tells you when a newer Android app is available and links to the APK (also in H:\downloads on the desktop). Installing it over the old one keeps your pairing.

- Open/close apps (close asks first), open websites, web search, open folders (Downloads, Documents... or a full folder path), Windows settings pages.
- Volume set/up/down, mute/unmute, brightness, dark/light mode, media play/pause, next, previous, stop.

Face and eye detailer (v1.6.2)
- AI Change selects face parts more tightly: eyes, left/right eye, eyebrows, mouth/lips, nose, face, pupils/iris. Each face is found by the body/face parsers (with CLIPSeg as a fallback), cropped, upscaled to 768 and segmented there; the eyes get a second 512px pass. Hands are told apart from arms on upscaled arm crops. On the desktop the CLIPSeg OpenVINO model is replaced by transformers CLIPSeg when it is missing.
- "fix eyes" / "fix face" in AI Change (desktop, laptop and phone Edit, which has Fix eyes and Fix face buttons) runs an ADetailer-style pass. The face is cropped with padding and upscaled to 768, inpainted at low denoise (0.32-0.45) with DreamShaper-8 inpaint + lineart ControlNet, keeping the detected iris colour. Candidates are scored on CLIP plausibility, symmetry and colour match, and the best one is pasted back at native resolution with a feathered edge. It only pastes when the result scores at least as well as the original; otherwise it keeps the original and says so. Both machines splits the candidates. Detail only: no identity or age change and no body reshaping.
- Image Gen has an "Auto-fix faces" option (on by default, also on the phone Gen tab). It runs the same pass after each image when NVIDIA is available.

1.9.2 - High quality fill for big cards
- High quality fill now handles big holes (an info card over the feet / ground) properly on an NVIDIA GPU: it crops
  the hole plus generous context (more above, where the subject continues), works at SD's own resolution (short side
  512 px), starts from the LaMa fill, uses strength 0.85, makes 2 candidates (fixed seeds, reproducible) and keeps the
  one whose edges match the surroundings best, then scales back and feathers it in.
- The prompt is built automatically: the Analyze vision model tags what is around the hole (e.g. "pumpkins, fog,
  lace-up boots, night") + "same art style, detailed". Text/card/weather words and faces/heads/animals are dropped,
  and the negative prompt blocks text, cards, frames, blur, duplicates and new faces/animals. It only continues what
  is already there - no body or clothing changes.
- If SD draws new objects into an area that is a plain/blurred backdrop (much busier than the picture beside the
  hole), that candidate is thrown away and the clean LaMa fill is kept (the note says so).
- When the mask covers more than 8% of the picture and an NVIDIA GPU is present, High quality turns on by itself
  (the result note says "turned on automatically"). Ticking the box forces it on for any size.

1.9.4 - Phone Heat tab
- New Heat tab. Lists apps from Android Usage Access (UsageStats plus usage events) over the last 6 hours, background activity first. The page says this is recent use, not a measured CPU or heat cause. Android does not give third-party apps a live per-app heat meter.
- If Usage access is off, the tab explains that and opens the system Usage access screen. Grant it once for NpuStudio Companion, then Refresh.
- Stop asks first. It uses killBackgroundProcesses when Android allows it and the app is not on screen. That only clears background processes (a foreground service can keep running, and Android may restart the app). It is not a Force stop. If a background kill isn't allowed, Stop opens that app's system App info page so you can tap Force stop. The App info button does the same. No root and no device admin.

1.9.5 - Heat row resource use
- Each Heat card also shows memory, CPU, and network when Android gives those numbers to a normal sideloaded app. Missing numbers stay N/A. This is still not a heat sensor.
- Memory is PSS (RSS only if the system actually returns summary.total-rss). Since Android 10, getProcessMemoryInfo is zeroed for every other UID, so on a Galaxy S24 Ultra memory is usually N/A except for NpuStudio itself.
- CPU percent needs two samples, so it shows after a later Refresh, and only for processes this app is allowed to see (again, usually only itself). Otherwise it can show that process's CPU time since it started, or N/A. /proc for other apps is hidden. dumpsys is not used.
- Network is Wi-Fi plus mobile bytes over the same 6 hours, from NetworkStatsManager, which Usage Access allows for apps on this user. Per-UID TrafficStats has been blocked for other apps since Android 7, so those calls are not shown as if they were the 6-hour total. If only one of Wi-Fi or mobile can be read, the card says so.
- Needs companion shell 5 (app 2.3). A shell 4 phone still shows the Heat list and asks for this update before filling in resources. latest_shell 5. min_shell stays 1. Web UI 1.9.5.
